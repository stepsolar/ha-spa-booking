# SPA Booking per Home Assistant

Integrazione SPA Booking per la gestione prenotazioni centro benessere/spa.

## Funzionalità
- Gestione appuntamenti, operatori, trattamenti, clienti
- Calendario integrato
- Notifiche WhatsApp/Telegram
- Richieste web
- Voucher e promozioni
- Backup/Ripristino completo JSON
- Esportazione/Importazione clienti CSV

## Installazione
1. Copiare `custom_components/spa_booking` in `config/custom_components/`
2. Copiare `www/spa_booking/` in `config/www/`
3. Riavviare Home Assistant
4. Aggiungere l'integrazione "SPA Booking"
